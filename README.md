# 日有所得 · 个人每日正反馈记录器

当前版本 1.2.0，新增跨天保留的“想做的事”，支持 GitHub Releases 检查更新、API 限流后备来源和本地发布脚本，见 [GITHUB-UPDATES.md](./GITHUB-UPDATES.md)。公开源码与 APK 位于 [AMIFYF/newyourself](https://github.com/AMIFYF/newyourself)。

现已在同一项目加入 Android App「每日正反馈」。Android 工程、APK、重建及 Android Studio 使用说明见 [ANDROID.md](./ANDROID.md)。网页版启动方式保持不变。

React + TypeScript + Vite 的本地 MVP。没有账号、后端、云同步或外部字体；安装依赖后，日常使用无需互联网。

## 启动

需要 Node.js 22.12+（本次使用 Node.js 24）。在本目录打开终端：

```sh
npm install
npm run dev
```

打开 **http://127.0.0.1:5173/**。当前交付已经安装好依赖，直接运行 `npm run dev` 即可。保持该终端运行。地址和端口固定，避免切换地址后读到另一个浏览器存储空间。

生产构建：`npm run build`。本地预览：`npm run preview`，同样使用上述固定地址；不要同时运行开发和预览服务。`dist/` 是生成的静态文件，不包含业务后端。

## 已实现

- 今日：五项完成度、每日不刷手机确认、一个核心任务、可增删修改及完成的“想做的事”、自动成果汇总。
- 专注：25/50 分钟，开始、暂停、继续、放弃、到时自动完成，手动补录；统一 XP 配置。
- 低刺激活动：持续计时、结束记录、手动输入活动和分钟，达到 30 分钟显示完成，超额正常累计。
- 历史：日期列表、每日详情、专注和低刺激明细。
- 统计：累计 XP、专注时间/次数、核心任务完成天数、5/5 天数、最近连续完成天数及最近 7 天。
- 数据：自动保存，JSON 导入/导出，清空两次确认，导入格式校验，存储失败和损坏数据保护。

## 数据与时间规则

存储键为 `daily-feedback-v1`。所有日期记录和两个计时器保存于一个 localStorage 文档，减少部分写入风险。汇总值从原始记录派生，避免 XP 和专注明细不同步。每个 Session 有唯一 ID；结算记录和清除计时器一并保存。支持 Web Locks 的浏览器会串行处理多标签页写入，其他标签页通过 storage 事件同步。

日期按设备本地年月日计算，不截取 UTC 日期。午夜自动切换今日，历史保留。未操作的日期不生成空记录，最近 7 天中显示为 0/5。

- 有效专注至少一次即完成专注项；补录使用同样 XP 规则。
- “想做的事”完成至少一件即完成该项。每件只在点击完成时获得 5 XP，未完成事项持续保留，可修改或删除。完成后归档到设备本地完成日期，保留标题及完成时间，历史归档只读。
- 核心任务必须点击完成，修改任务文字会取消其完成状态。
- 不刷手机必须主动点击完成。
- 低刺激累计至少 30 分钟才完成，计时精确保存，显示保留最多两位小数。
- 专注使用剩余毫秒与运行起点计算；暂停期间不增加时间。关闭页面仍按自然流逝时间计算，重新打开后补结算。
- 跨日专注归入实际到时的本地日期；低刺激活动归入点击“结束并记录”的本地日期，不拆分跨日活动。
- 连续天数是相邻自然日达到 5/5 的数量。今天未满 5/5 时从昨天向前计算；今天完成则包含今天。

导入采用整体替换，并先校验版本、日期、记录字段、XP、重复 ID 和计时器。导入前有确认；清空有两次确认。备份含正在进行的计时状态。

1.2.0 使用数据格式 v2，启动时自动兼容旧版 v1 记录及备份，继续使用原存储键，不清空历史或计时器。旧推进文本保留为历史只读记录，不转换成未完成事项、不补发 XP；升级前的自然日沿用原推进完成判定，升级当天开始使用新规则。v2 备份需用 1.2.0 或更新版本导入。

## 验证

```sh
npm run typecheck
npm run build
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
```

本次浏览器验证使用本机 Microsoft Edge。Windows PowerShell 可使用现有 Edge，避免下载 Chromium：

```powershell
$env:PW_CHANNEL = 'msedge'
npm run test:e2e
```

测试通过虚拟时钟推进时间，无需实际等待 25/50 分钟。测试覆盖完成边界、暂停、恢复、跨日、重复结算、完整 5/5 流程、备份往返、损坏备份拒绝、清空确认、存储失败、逐字输入、手机布局，以及关闭并重新启动浏览器后的数据保留。

## 使用边界

数据属于当前浏览器配置和访问地址。清除浏览器网站数据、使用隐私模式或更换浏览器不会保留同一份数据，请用 JSON 备份迁移。普通使用在 localhost 上运行，推荐当前版本 Edge/Chrome，以便使用 Web Locks 防止并发写入。系统时间调整会影响运行中计时器；本地工具不校验用户是否真实专注。

没有已知阻塞 MVP 主流程的问题。未实现需求外的账户、联网同步、等级、社交或奖励兑换。

实现时查阅了 [React 官方文档](https://react.dev/reference/react/useSyncExternalStore) 和 [Vite 官方文档](https://vite.dev/guide/)。
